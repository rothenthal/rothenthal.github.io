CREE Report Generator

Use comments as hidden PPTX template instructions.

Drop a PowerPoint template, an Excel data workbook, and any replacement images, then download a filled copy.

Replacement values use column B as the key and column G as the value on the Input/Output sheets. Picture comments can point directly to uploaded files, like {render.jpeg}.

Numeric replacements follow the selected template text: 00.0 keeps one decimal, while 000 keeps no decimals.
